# CasaFirme

Hub gratuito para propietarios de Miami-Dade que buscan casos de code enforcement, multas y liens.

## Características
- Búsqueda por dirección o folio
- Bilingüe (ES/EN)
- Clasificación de propiedades (single-family, duplex, multifamily, commercial)
- Información sobre homestead y school vs non-school
- Flujo de lead hacia servicios profesionales (Arkiteko)

## Despliegue
Sitio estático. Puedes desplegarlo en Netlify, Vercel o GitHub Pages.

## Notas
Versión demo. En producción se conecta a records públicos del Property Appraiser y GIS de Miami-Dade.
